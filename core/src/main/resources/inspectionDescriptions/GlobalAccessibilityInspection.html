Reports accessibility (a11y) issues in HTML, JS, JSX, TS, TSX, and Vue files by checking each element against a configurable set of WCAG/ARIA rules.

Examples include images missing an alt attribute, form controls without an associated label, ambiguous link text, invalid or redundant ARIA roles/attributes, and elements that violate WCAG/ARIA element-role constraints.

Rules are checked in a single PSI tree traversal per file, including elements inside injected template strings. Enable or disable individual rules, or switch to a project-level JSON config file, in Settings | Editor | Optimus Accessibility.
